# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive. Assume good intent, give and accept feedback on the work rather than the person, and keep discussions useful and welcoming to everyone, whatever their background or experience. Harassment, personal attacks, and sharing others' private information are not acceptable.

If you experience or see a problem, please report it privately to the maintainer through their GitHub profile: <https://github.com/PreillySMP>. Public issues and comments are not the place for it.
