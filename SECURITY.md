# Security Policy

## Reporting a vulnerability

Please report security problems privately, not in public issues.

Go to the repository's **Security** tab and click **Report a vulnerability**. This uses GitHub's private vulnerability reporting, so only the maintainer sees your report.

Include what you found, the steps to reproduce it, and what you think the impact is. You will get a reply when the maintainer has time to look, and the fix will be credited to you if you want that.

## Supported versions

Only the latest version on the `main` branch is supported. Older releases won't get fixes, so please update before reporting.

## Scope

Mamma's Chef is designed to run on your own computer for personal use. It is not built to be exposed to the internet. The README explains the local setup and its known limits, such as the default local database settings, and reports about those limits are still welcome.
